# LinkDeck 商店资料与隐私模板

## 建议的商店文案

- 名称：LinkDeck
- 简短描述：按分组收藏常用网址，点击即可在新标签页打开。
- 完整描述：LinkDeck 是一个轻量的网址收藏卡组，帮助你把经常访问的网站按“常用”“工作”“灵感”等主题收好。安装后，将它固定到浏览器工具栏；点击图标即可在紧凑的浮窗中浏览分组和收藏。你可以手动输入网址，也可以在打开网页时点“收藏当前页”，由 LinkDeck 预填页面标题和网址，确认后再保存。每个网站都可以改名、修改网址或移动到其他分组；空分组可以删除，避免误删其中的收藏。普通点击会在前台新标签页打开网站，按住 Cmd 或 Ctrl 点击则会在后台打开，便于一次打开多条链接。收藏数据使用浏览器内建同步存储：登录同一 Chrome 账号的 Chrome 设备可以同步，登录同一 Edge 账号的 Edge 设备可以同步；Chrome 与 Edge 之间不会互通。LinkDeck 不注入网页、不读取浏览历史、不运行远程代码。为了展示网站图标，浮窗会向 favicon.im 按域名请求图标；服务不可用时会显示本地首字母图标。
- 单一用途：帮助用户按分组保存并快速打开自己主动添加的网站。

## 权限说明

- `storage`：保存分组和收藏，并使用浏览器提供的同步存储在同一浏览器账号设备间同步。
- `activeTab`：仅当用户点击“收藏当前页”时，读取当前标签页的标题和网址以预填表单。用户确认保存前不会写入收藏。

## 隐私声明模板

LinkDeck 不运营服务器，不出售、共享或上传用户收藏数据。收藏内容保存在浏览器的同步存储中，并由用户的浏览器账号同步设置控制。

为显示网站图标，LinkDeck 会在 popup 展示收藏时向 `favicon.im` 请求该收藏网址的域名图标。请求只包含域名，不包含完整路径、查询参数、页面标题或用户输入的分组名称；该服务仍可看到请求的域名和用户 IP。图标服务不可用时，扩展会显示本地首字母占位图。

扩展不加载远程 JavaScript、不注入网页、不使用分析 SDK，也不收集账户、密码、支付信息或浏览历史。
