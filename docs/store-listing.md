# LinkDeck 商店资料与隐私模板

## 建议的商店文案

- 名称：LinkDeck
- 简短描述：用多标签收藏常用网址，点击即可在新标签页打开。
- 完整描述：LinkDeck 是一个轻量的网址收藏卡组，帮助你用“常用”“工作”“灵感”等标签灵活整理经常访问的网站；一个网站可以同时拥有多个标签，也可以暂时不加标签。安装后，将它固定到浏览器工具栏；点击图标即可在紧凑的浮窗中筛选标签和收藏。你可以手动输入网址，也可以在打开网页时点“收藏当前页”，由 LinkDeck 预填页面标题和网址，确认后再保存。当前页面已经收藏时，工具栏图标会显示 ✓ 角标。每个网站都可以改名、修改网址和标签；删除标签只会移除标签，不会删除网站。普通点击会在前台新标签页打开网站，按住 Cmd 或 Ctrl 点击则会在后台打开，便于一次打开多条链接。收藏数据使用浏览器内建同步存储：登录同一 Chrome 账号的 Chrome 设备可以同步，登录同一 Edge 账号的 Edge 设备可以同步；Chrome 与 Edge 之间不会互通。用户也可以主动配置自己的 GitHub secret Gist，在不同浏览器之间自动同步全部收藏；首次绑定和发生冲突时都由用户明确选择数据来源。在 Popup 关闭时，按下 Command+Shift+P（Windows/Linux 为 Ctrl+Shift+P），即可在当前网页打开一个 VS Code 风格的悬浮搜索层，默认搜索当前浏览器窗口已经打开的标签页；按 Tab 可切换到浏览器历史记录，按 Shift+Tab 切回，并用键盘快速打开结果。历史记录搜索最多展示最近 100 条，只在用户主动切换到历史模式后读取，并且不会上传、写入收藏或参与同步。搜索层只在用户明确按下快捷键时临时注入当前页面，不运行远程代码。为了展示收藏网站图标，浮窗会向 favicon.im 按域名请求图标；服务不可用时会显示本地首字母图标。
- 单一用途：帮助用户按标签保存并快速打开自己主动添加的网站。

## 权限说明

- `storage`：保存标签和收藏，并使用浏览器提供的同步存储在同一浏览器账号设备间同步。
- `tabs`：读取当前窗口标签页的标题、网址和浏览器提供的网站图标，用于本地显示标签页搜索结果；也读取当前打开标签页的网址以判断是否已收藏并更新工具栏角标。不会上传标签页或角标检测结果。
- `history`：仅当用户在标签页搜索浮层中主动按 `Tab` 切换到历史模式时，读取浏览器历史记录的标题、网址和最近访问时间，最多返回 100 条用于本地显示；不修改、上传、同步或导出历史记录。
- `activeTab`：仅在用户点击扩展或使用快捷键主动触发功能时，临时访问当前网页；不申请 `<all_urls>`。
- `scripting`：在快捷键触发的当前网页中注入标签页搜索悬浮层；不加载远程 JavaScript。
- `https://api.github.com/*`：仅在用户主动启用 Gist 同步后读写该用户绑定的 Gist；用于上传、下载和校验完整收藏快照。

## 隐私声明模板

LinkDeck 不运营服务器，不出售或共享用户收藏数据。默认情况下，收藏内容保存在浏览器的同步存储中，并由用户的浏览器账号同步设置控制。

如果用户主动启用 GitHub Gist 同步，LinkDeck 会通过 `api.github.com` 向用户自己的 secret Gist 上传和下载完整标签与收藏数据，并在本机数据变更后自动同步。用于请求的细粒度 GitHub 访问令牌只保存于当前浏览器的扩展本地存储，不会同步到其他浏览器、导出到 JSON 文件、发送给 LinkDeck 开发者或写入日志。用户可随时断开同步；断开不会删除本机数据或 GitHub 上的 Gist。

GitHub secret Gist 不会公开展示或搜索，但并非真正私有：任何拿到 Gist 链接的人都可以读取其中的明文收藏。用户不应将敏感网址同步到 Gist。

为显示网站图标，LinkDeck 会在 popup 展示收藏时向 `favicon.im` 请求该收藏网址的域名图标。请求只包含域名，不包含完整路径、查询参数、页面标题或用户输入的标签名称；该服务仍可看到请求的域名和用户 IP。图标服务不可用时，扩展会显示本地首字母占位图。

扩展不加载远程 JavaScript、不申请 `<all_urls>`、不使用分析 SDK，也不会修改浏览器历史。标签页搜索只在用户明确按下 Command+Shift+P（Windows/Linux 为 Ctrl+Shift+P）后临时注入当前网页，默认在本地读取当前窗口的标签页标题、网址和浏览器提供的网站图标；用户主动按 `Tab` 切换到历史模式后，扩展通过浏览器历史 API 读取最多 100 条匹配记录的标题、网址和最近访问时间。这些标签页和历史数据只用于当次搜索，不写入收藏、不参与同步、不导出，也不会上传到 LinkDeck 或第三方服务。扩展也会在本地读取当前打开标签页的网址，用于显示是否已收藏的角标；该检测结果不会上传。Chrome/Edge 内部页、商店页和其他受保护页面可能拒绝临时注入。GitHub 令牌仅用于用户本人启用的 Gist API 请求，不会离开该用户的浏览器与 GitHub API 通信链路。

> 商店提交时，请将以上文字发布到你自己可公开访问的隐私政策 URL，并按实际发布版本重新核对。
